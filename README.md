# optcg-deck-buyer

เครื่องมือจดการซื้อการ์ด One Piece Card Game มาประกอบเด็ค: ลากการ์ดไปไว้กับคนขายแต่ละคน
แล้วดูว่าซื้อกับใครกี่บาท ได้ใบไหนบ้าง และต้นทุนรวมของเด็ค (ค่าการ์ด + ค่าส่ง)

## ใช้งาน

- **ในเครื่อง (แนะนำ):** ดับเบิลคลิก `start.bat` จะเปิดแอปที่ `http://127.0.0.1:8730` (ต้องมี Python)
  รูปการ์ดจากเกมจะติดในรูปที่ส่งออกด้วย ปิดหน้าต่างดำเพื่อหยุด
- เปิด `index.html` ตรงๆ ก็ใช้ได้ แต่รูปที่ส่งออกจะเป็นกรอบชื่อแทนรูปการ์ด
- วางทั้งโฟลเดอร์บนโฮสต์ static (GitHub Pages ฯลฯ) ได้ ใช้บนมือถือได้

ข้อมูลของแต่ละแบบแยกกัน (`start.bat`, ไฟล์ตรง, เว็บ) ย้ายด้วย Export / Import

1. เพิ่มการ์ดเข้าเด็ค: พิมพ์รหัส, ปุ่ม `.deck` (ไฟล์ OPTCGSim), ลากไฟล์ `.deck` มาวาง
   หรือปุ่ม **วางเด็ค** (ข้อความ `4xOP01-016` หรือ HTML หน้าเด็คจาก oplaytcg.com)
2. **+ คนขาย** แล้วใส่ค่าส่ง และ **ราคารวม** ถ้าคนขายคิดเป็นยอดเดียว
3. ลากการ์ดไปวางในกล่องคนขาย (จอแคบ: แตะการ์ดแล้วแตะกล่อง)
4. ดูยอดค่าการ์ด ค่าส่ง ต้นทุนรวม และจำนวนที่ยังขาดที่แถบด้านบน
5. **ส่งออกรูป** การ์ดที่ยังขาด (มือถือ: เมนู ⋯) ไว้ส่งให้คนขาย

มือถือ: แท็บด้านล่างสลับ การ์ด / คนขาย · แตะการ์ดแล้วเลือกคนขาย · กดค้างดูรูปใหญ่

ข้อมูลเก็บในเบราว์เซอร์เครื่องนั้น ย้ายเครื่องด้วย **Export / Import** (ไฟล์ JSON)

## รูปการ์ด

- ชื่อและรูปจาก [optcgapi.com](https://optcgapi.com)
- ถ้าวางโฟลเดอร์นี้ข้างโฟลเดอร์เกม (`../Builds_Windows/OPTCGSim_Data/...`) จะใช้รูปจากเกมในเครื่องก่อน
