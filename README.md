# optcg-deck-buyer

เครื่องมือจดการซื้อการ์ด One Piece Card Game มาประกอบเด็ค: ลากการ์ดไปไว้กับคนขายแต่ละคน
แล้วดูว่าซื้อกับใครกี่บาท ได้ใบไหนบ้าง และต้นทุนรวมของเด็ค (ค่าการ์ด + ค่าส่ง)

## ใช้งาน

- **ในเครื่อง (แนะนำ):** ดับเบิลคลิก `start.bat` จะเปิดแอปที่ `http://127.0.0.1:8730` (ต้องมี Python)
  รูปการ์ดจากเกมจะติดในรูปที่ส่งออกด้วย ปิดหน้าต่างดำเพื่อหยุด
- เปิด `index.html` ตรงๆ ก็ใช้ได้ แต่รูปที่ส่งออกจะเป็นกรอบชื่อแทนรูปการ์ด
- วางทั้งโฟลเดอร์บนโฮสต์ static (GitHub Pages ฯลฯ) ได้ ใช้บนมือถือได้

ข้อมูลของแต่ละแบบแยกกัน (`start.bat`, ไฟล์ตรง, เว็บ) ย้ายด้วย Export / Import

1. เพิ่มการ์ดเข้าเด็ค: พิมพ์รหัส, ปุ่ม `.deck` (ไฟล์ OPTCGSim), ลากไฟล์ `.deck` มาวาง
   หรือปุ่ม **วางเด็ค** (ข้อความ `4xOP01-016` หรือ HTML หน้าเด็คจาก oplaytcg.com)
2. **+ คนขาย** แล้วใส่ค่าส่ง และ **ราคารวม** ถ้าคนขายคิดเป็นยอดเดียว
3. ลากการ์ดไปวางในกล่องคนขาย (จอแคบ: แตะการ์ดแล้วแตะกล่อง)
4. ดูยอดค่าการ์ด ค่าส่ง ต้นทุนรวม และจำนวนที่ยังขาดที่แถบด้านบน
5. **ส่งออกรูป** การ์ดที่ยังขาด (มือถือ: เมนู ⋯) ไว้ส่งให้คนขาย

มือถือ: แท็บด้านล่างสลับ การ์ด / คนขาย · แตะการ์ดแล้วเลือกคนขาย · กดค้างดูรูปใหญ่

ข้อมูลเก็บในเบราว์เซอร์เครื่องนั้น ย้ายเครื่องด้วย **Export / Import** (ไฟล์ JSON)
เวอร์ชันบน Vercel บันทึกขึ้น Turso อัตโนมัติด้วย (ด้านล่าง) ทุกเครื่องเห็นข้อมูลชุดเดียวกัน

## บันทึกขึ้นเซิร์ฟเวอร์ (Vercel + Turso)

เวอร์ชันบน Vercel บันทึกข้อมูลลง Turso ให้เอง ไม่ต้องกดอะไร ไม่มีรหัส
เปิดจากเครื่องไหนก็เห็นข้อมูลชุดเดียวกัน ไม่มีเน็ตก็แก้ต่อได้ (เก็บไว้ในเครื่อง) แล้วบันทึกเมื่อเน็ตกลับมา
token ของ Turso อยู่ฝั่งเซิร์ฟเวอร์ (`api/`) เท่านั้น ไม่อยู่ในหน้าเว็บ

**ตั้งค่าครั้งเดียว**

1. [Turso](https://app.turso.tech) → **Create Database** ชื่อ `optcg-deck-buyer` (แยกจากฐานข้อมูลอื่น)
2. เปิดฐานข้อมูลนั้น คัดลอก **URL** (ขึ้นต้น `libsql://`) แล้ว **Generate Token** แบบ Read & Write
3. Vercel → โปรเจกต์ → **Settings → Environment Variables** เพิ่ม 2 ค่า (ติ๊ก Sensitive ได้):
   `TURSO_DATABASE_URL` = URL, `TURSO_AUTH_TOKEN` = token
4. **Redeploy** deploy ล่าสุด (Deployments → ⋯ → Redeploy) เพื่อให้ค่าใหม่มีผล

**ใช้งาน:** มุมขวาบนมีป้ายสถานะ (มือถือ: จุดที่ปุ่ม ⋯) **บันทึกแล้ว** / **กำลังบันทึก…** / **ออฟไลน์**
กดป้าย (มือถือ: เมนู ⋯ → ประวัติ / กู้คืน) เพื่อดูประวัติและกู้คืน

- **แก้จากสองเครื่องไม่ตรงกัน** (เช่นมือถือแก้ตอนไม่มีเน็ต) → ใช้ชุดที่ **แก้ล่าสุด** อัตโนมัติ ไม่ถาม
  ชุดที่ไม่ได้ใช้เก็บลงประวัติ กู้คืนได้
- **ประวัติ:** สำรองอัตโนมัติไม่ถี่กว่าทุก 10 นาที + ชุดที่ถูกทับ + ชุดก่อนกู้คืน เก็บล่าสุด 50 ชุด
- **เด็คที่เปิดอยู่เป็นของแต่ละเครื่อง** (มือถือเปิดเด็ค B ไม่ทำให้คอมกระโดดไปเด็ค B)
- **ไม่มีรหัส** (เลือกไว้แบบนี้): ใครรู้ลิงก์ก็อ่านหรือแก้ข้อมูลได้ ถ้าถูกลบหรือทับ กู้จากประวัติได้
- เปิด `index.html` ตรง ๆ หรือผ่าน `start.bat` ไม่มีเซิร์ฟเวอร์ → เก็บในเครื่องอย่างเดียว

## รูปการ์ด
