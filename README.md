# optcg-deck-buyer

เครื่องมือจดการซื้อการ์ด One Piece Card Game มาประกอบเด็ค: ลากการ์ดไปไว้กับคนขายแต่ละคน
แล้วดูว่าซื้อกับใครกี่บาท ได้ใบไหนบ้าง และต้นทุนรวมของเด็ค (ค่าการ์ด + ค่าส่ง)

## ใช้งาน

- **ในเครื่อง (แนะนำ):** ดับเบิลคลิก `start.bat` จะเปิดแอปที่ `http://127.0.0.1:8730` (ต้องมี Python)
  รูปการ์ดจากเกมจะติดในรูปที่ส่งออกด้วย ปิดหน้าต่างดำเพื่อหยุด
- เปิด `index.html` ตรงๆ ก็ใช้ได้ แต่รูปที่ส่งออกจะเป็นกรอบชื่อแทนรูปการ์ด
- วางทั้งโฟลเดอร์บนโฮสต์ static (GitHub Pages ฯลฯ) ได้ ใช้บนมือถือได้

ข้อมูลของแต่ละแบบแยกกัน (`start.bat`, ไฟล์ตรง, เว็บ) ย้ายด้วย Export / Import

1. เพิ่มการ์ดเข้าเด็ค: พิมพ์รหัส, ปุ่ม `.deck` (ไฟล์ OPTCGSim), ลากไฟล์ `.deck` มาวาง
   หรือปุ่ม **วางเด็ค** (ข้อความ `4xOP01-016` หรือ HTML หน้าเด็คจาก oplaytcg.com)
2. **+ คนขาย** แล้วใส่ค่าส่ง และ **ราคารวม** ถ้าคนขายคิดเป็นยอดเดียว
3. ลากการ์ดไปวางในกล่องคนขาย (จอแคบ: แตะการ์ดแล้วแตะกล่อง)
4. ดูยอดค่าการ์ด ค่าส่ง ต้นทุนรวม และจำนวนที่ยังขาดที่แถบด้านบน
5. **ส่งออกรูป** การ์ดที่ยังขาด (มือถือ: เมนู ⋯) ไว้ส่งให้คนขาย

มือถือ: แท็บด้านล่างสลับ การ์ด / คนขาย · แตะการ์ดแล้วเลือกคนขาย · กดค้างดูรูปใหญ่

ข้อมูลเก็บในเบราว์เซอร์เครื่องนั้น ย้ายเครื่องด้วย **Export / Import** (ไฟล์ JSON)
หรือเปิด **ซิงก์ข้ามเครื่อง** (ด้านล่าง) ให้ทุกเครื่องเห็นข้อมูลชุดเดียวกัน

## ซิงก์ข้ามเครื่อง (Vercel + Turso)

ใช้ได้เฉพาะตอน deploy บน Vercel เพราะต้องมีฟังก์ชันฝั่งเซิร์ฟเวอร์ `api/sync` ถือ token ของ Turso
(token ไม่เคยไปอยู่ในหน้าเว็บ) ข้อมูลในเบราว์เซอร์ยังเป็นหลัก ไม่มีเน็ตก็ใช้ได้ แล้วซิงก์ทีหลัง

**ตั้งค่าครั้งเดียว**

1. [Turso](https://app.turso.tech) → **Create Database** ชื่อ `optcg-deck-buyer` (แยกจากฐานข้อมูลอื่น)
2. เปิดฐานข้อมูลนั้น คัดลอก **URL** (ขึ้นต้น `libsql://`) แล้ว **Generate Token** แบบ Read & Write
3. Vercel → โปรเจกต์ → **Settings → Environment Variables** เพิ่ม 3 ค่า (ติ๊ก Sensitive ได้):

   | ชื่อ | ค่า |
   |---|---|
   | `TURSO_DATABASE_URL` | URL จากข้อ 2 |
   | `TURSO_AUTH_TOKEN` | token จากข้อ 2 |
   | `SYNC_PASSWORD` | รหัสที่คุณตั้งเอง ยาว ๆ เดายาก (ใช้ใส่ในแอปทุกเครื่อง) |

4. **Redeploy** (Deployments → ⋯ → Redeploy) เพื่อให้ค่าใหม่มีผล

**ใช้งาน:** กดปุ่ม **ซิงก์** (มือถือ: เมนู ⋯ → ซิงก์ข้ามเครื่อง) ใส่ `SYNC_PASSWORD`
เครื่องแรกจะส่งข้อมูลขึ้นไป เครื่องที่ยังว่างจะรับข้อมูลลงมาเอง แก้อะไรแล้วส่งขึ้นอัตโนมัติ
และดึงของใหม่ตอนกลับมาเปิดแท็บ

- **เด็คที่เปิดอยู่เป็นของแต่ละเครื่อง** ไม่ซิงก์ (มือถือเปิดเด็ค B ไม่ทำให้คอมกระโดดไปเด็ค B)
- ถ้าสองเครื่องแก้ไม่ตรงกัน แอปจะไม่ทับเงียบ ๆ แต่ถามว่าจะใช้ชุดคลาวด์หรือชุดเครื่องนี้
- ซิงก์ทั้งชุดเป็น JSON แถวเดียว ถ้าแก้พร้อมกันสองเครื่อง ชุดที่ส่งทีหลังต้องเลือกตามข้างบน
- ปุ่ม Export ยังใช้เป็นข้อมูลสำรองได้ตามปกติ
